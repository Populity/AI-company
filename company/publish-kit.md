## Как выложить вручную (пока нет автопостинга)

**Instagram Reels (в телефоне):** «+» внизу → **Reels** → выбрать скачанное видео → **Далее** →
вставить подпись → внизу **Дополнительные настройки** → включить **Метка ИИ / AI label** → **Поделиться**.
Потом открыть ролик → комментарий → вставить закреплённый текст → долгое нажатие на комментарий → **Закрепить**.

**YouTube Shorts (приложение YouTube):** «+» → **Создать Short** → загрузить видео → **Далее** →
вставить название → **Описание** → вставить описание → **Ещё / Настройки** →
**Изменённый или синтетический контент: Да** → **Загрузить Short**.

Названия кнопок могут немного отличаться в твоей версии приложения.
