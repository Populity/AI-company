# Итог: бесплатное видео без водяного знака (2026-10-23)

Отчёты: `us-eu.md`, `asia.md`, `open-source.md`, `../free-tools-report.md`.

## Проверено на деле
- **LTX-2.3 (Lightricks) через бесплатный Hugging Face Space — РАБОТАЕТ.** Без аккаунта, без водяного знака, звук и речь на английском, 576×1024. Лимит анонима: 5 с на клип (10 с — отказ по квоте). Коммерция разрешена (лицензия LTX: бесплатно при выручке < $10 млн). Минус: длинная реплика тараторится — писать ≤12 слов на 5 с. С бесплатным аккаунтом HF квота больше.
- Renderforest без подписки — водяной знак на лице, не годится.
- Higgsfield Seedance Mini 480p — 5 кр./10 с, без знака; основной платный.

## Не годится (видимый знак или запрет коммерции на бесплатном уровне)
Runway, Luma, Pika, HeyGen, Synthesia, D-ID, Captions, Krea, Bing, Google Flow (знак «Veo»), Kling, Hailuo, Vidu, PixVerse, Dreamina/Jimeng, Doubao. Sora и Amazon Nova Reel закрыты в 2026.

## Бесплатно, но только руками в телефоне/браузере (агент не может)
YouTube Create / Shorts (Gemini Omni Flash, клипы до 10 с, только невидимый SynthID), Google Vids (~6 клипов/мес), Adobe Firefly (уверенность низкая). Из России — через VPN и зарубежный аккаунт.

## План
1. Основной бесплатный конвейер: LTX-2.3 Space (клипы по 5 с) + кадры Higgsfield (0.25 кр.) + склейка/субтитры в песочнице. Серия 30 с = 6 клипов.
2. Нужен бесплатный аккаунт Hugging Face и токен (секрет HF_TOKEN) — квота вырастет.
3. Запасной: Kaggle (30 ч GPU/нед) + InfiniteTalk + голос Kokoro — нужен аккаунт Kaggle с телефоном.
